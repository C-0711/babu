Diesen Knopf auf dem iPhone in Safari drücken.
So geht's:
  1. Diese Seite auf dem iPhone in Safari öffnen: babu.0711.io/app
  2. Oben auf „babu installieren" tippen und Erlauben wählen.
  3. Kurz warten — das Icon mit dem kleinen „b" erscheint auf dem Homescreen.
  4. Falls das iPhone beim ersten Start fragt: Einstellungen → Allgemein → VPN & Geräteverwaltung → dem Eintrag vertrauen.
Klappt es nicht?

Die App läuft in dieser Testphase nur auf freigeschalteten iPhones. Deins ist noch nicht dabei? Kurz Bescheid geben — wir schalten es frei, danach funktioniert der Knopf auch bei dir.
