TestFlight laden
Deine Einladung kommt per E-Mail — der Knopf holt nur die App, die sie öffnet.
So geht's:
  1. TestFlight aus dem App Store laden (Knopf oben) — das ist Apples App für Einladungen.
  2. Die Einladungs-E-Mail von babu auf dem iPhone öffnen und auf „In TestFlight anzeigen" tippen.
  3. In TestFlight auf Installieren. Das Icon mit dem kleinen „b" erscheint auf dem Homescreen.
  4. babu öffnen, mit E-Mail und Passwort anmelden — fertig.
